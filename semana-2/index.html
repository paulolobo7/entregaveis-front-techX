Por que usar HTML semântico?

Tags semânticas como header, nav, main, article, aside e footer descrevem o significado de cada parte da página. Isso ajuda os mecanismos de busca a entender o conteúdo e torna o site mais acessível para quem usa leitores de tela.

Primeiros passos com CSS

Depois de estruturar a página com HTML, o próximo passo é estilizá-la com CSS. Com propriedades de cores, espaçamentos e Flexbox, é possível transformar uma página simples em um layout organizado e agradável.
